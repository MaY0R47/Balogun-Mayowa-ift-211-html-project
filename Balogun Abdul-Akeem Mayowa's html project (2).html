Introduction to Web Technologies

Understanding the tools that make the Web possible

Introduction Internet World Wide Web Technologies Browsers

1. Introduction

Web technologies are the tools, languages and systems used to create and use websites and web applications. They allow people to learn, communicate, shop and do business online.

2. What is the Internet?

The Internet is a worldwide network of computers connected together to share information. It uses rules called protocols, like TCP/IP, to allow computers to communicate.

It provides services like email, file sharing, video calls and the World Wide Web.

Note: The Internet is the network. The Web is one service that runs on it.

3. What is the World Wide Web?

The World Wide Web (WWW) is a system of web pages connected by links. It was invented by Tim Berners-Lee in 1989.

When you click a link, your browser asks a web server for that page, and the server sends it back for you to view. A page can contain text, images, videos and links.

Simple way to remember: Internet = Road. Web = Cars using the road.

4. Basic Web Technologies

4.1 HTML

HTML (HyperText Markup Language) is used to build the structure of a page. It creates headings, paragraphs, links, lists and images.

4.2 CSS

CSS (Cascading Style Sheets) controls how the page looks. It adds colours, fonts, spacing and layout. This page is cream because of CSS.

4.3 JavaScript

JavaScript adds action to a page. It makes buttons work, checks forms and makes pages interactive.

Remember: HTML = Structure, CSS = Style, JavaScript = Action.

5. Examples of Web Browsers

A browser is an app that lets you open and view websites. Examples are:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Apple Safari
  • Opera

6. Conclusion

Web technologies make the modern web possible. The Internet provides the network, the Web provides the pages, and HTML, CSS and JavaScript work together to build them.
