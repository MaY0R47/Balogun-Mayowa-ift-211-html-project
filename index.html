1. Introduction to Web Technology

Web technology is the collection of tools, languages, protocols and systems used to create, display and manage websites and web applications on the Internet. It allows people to communicate, learn, shop, watch videos, bank and do business online from anywhere in the world.

Every website you visit, from Google to WhatsApp Web to JAMB portal, is built using web technologies. Without them, the Internet would just be connected computers with no way to show information in an organized and beautiful way.

Web technology is not just about building websites. It is also about how information is stored, sent, protected and displayed to users quickly and safely.

2. Brief History of Web Technology

The World Wide Web was invented by Tim Berners-Lee in 1989 at CERN in Switzerland. At first, websites were just simple text pages with links.

Later, HTML improved, CSS was introduced for design, and JavaScript was added for interactivity. Today we have modern tools like React, YouTube, online banking and AI-powered websites, all built on the same basic foundation.

3. How The Web Works

When you type a website address like www.google.com, these 4 steps happen in seconds:

  1. You type the address in your browser
  2. Your browser sends a request to a web server using HTTP/HTTPS
  3. The server finds the website files and sends them back
  4. Your browser displays the files as a beautiful web page

Image: Servers that store and deliver websites to millions of users.

Simple way to remember: Internet = Road. Web = Cars, Shops and Houses using the road. Browser = Driver that takes you there.

4. Main Types of Web Technologies

  • HTML (HyperText Markup Language) - Builds the structure of a web page like headings, paragraphs, images
  • CSS (Cascading Style Sheets) - Adds colours, fonts, spacing and layout. This page is cream because of CSS
  • JavaScript - Adds action, like buttons, forms, pop-ups and sliders
  • HTTP / HTTPS - Rules for sending web pages. HTTPS is the secure version
  • URL - The address of a web page, e.g. www.google.com
  • Web Browser - App used to view websites
  • Web Server - Computer that stores and delivers websites
  • Database - Stores user data like names and passwords e.g. MySQL

Examples of Web Browsers

  1. Google Chrome - Most popular in the world
  2. Mozilla Firefox - Open source and privacy-focused
  3. Microsoft Edge - Built into Windows
  4. Apple Safari - Built into iPhone and Mac
  5. Opera - Has free VPN and ad-blocker
  6. Brave - Blocks ads and trackers

5. Frontend vs Backend

Web technology is divided into two main parts:

Frontend is what the user sees - the design, buttons, colours and text. It uses HTML, CSS and JavaScript.

Backend is what the user does NOT see - the server, database and logic that saves your login, processes payments and loads your data. It uses languages like Python, PHP and Node.js.

Example: On Instagram, the photos and buttons you see are Frontend. The system that saves your photos and shows your followers is Backend.

6. Uses and Importance of Web Technology

Web technology is important in our daily life because it is used for:

  • Education: Online classes, JAMB, e-learning
  • Business: Online shops like Jumia, Konga
  • Banking: GTB app, Opay, Palmpay
  • Communication: WhatsApp, Email, Zoom
  • Entertainment: YouTube, Netflix, TikTok
  • Government: NIMC, INEC, Passport portal

Without web technology, it would be very hard to learn, work or do business in the modern world.

8. Conclusion

In conclusion, web technology is what makes the modern Internet possible. HTML gives structure, CSS gives beauty, and JavaScript gives life to web pages. Behind the scenes, servers, databases and protocols work together to deliver information in seconds.

As technology grows, web technology will continue to improve with AI websites, Progressive Web Apps and faster, safer browsing for everyone.
